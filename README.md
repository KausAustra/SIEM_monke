# SIEM_monke
A lightweight Tampermonkey script to enhance your MaxPatrol SIEM experience.

### Key Features
- **Smart Sidebar:** Instant access to pre-configured filters.
- **Parent-Event Navigation:** Automatic links to parent events via `.parent.` fields.

### Quick Start
1. **Install Tampermonkey** (available for Chrome, Firefox, and Edge).
2. **Add Script:** Click on the Tampermonkey icon -> "Create a new script".
3. **Copy & Paste:** Paste the code from `siem_monkey.js` into the editor and save.
4. **Enjoy:** Refresh your SIEM events page and watch the magic happen.
