# SIEM_monke

Легкий Tampermonkey-скрипт для оптимизации работы с интерфейсом MaxPatrol SIEM.

### Основные возможности

- **Smart Sidebar:** быстрый доступ к преднастроенным фильтрам прямо на боковой панели.
- **Переход к родительским событиям:** автоматическая линковка родительских событий на основе полей .parent.

### Инструкция по установке

1. Установите расширение Tampermonkey (поддерживается в Chrome, Firefox и Edge).
2. Создайте новый скрипт: кликните по иконке Tampermonkey → «Создать новый скрипт» (Create a new script).
3. Добавьте код: скопируйте содержимое файла SIEM_monkey.user.js, вставьте его в редактор расширения и сохраните (Ctrl+S).
4. Готово: обновите страницу с событиями SIEM, чтобы изменения вступили в силу.
